# 当前进度：11 月 7—8 日填充修复与 Rust 重构

更新时间：2026-11-08（北京时间）。范围：2026-11-07 至 2026-11-08，当前 `refactor/rust-core` 独立分支。本文汇总已经完成的实现和验收；此次文档整理不重新运行 OCR、翻译或性能评测。

## 当前结论

macOS 的视觉辅助、本地连接配置、中文横排及背景清字已落地，35 页已有译文填充从早期基线的 206 段提升到 244 段。以修复后的稳定版为基线，Rust 候选版完成业务核心迁移，35 页最终渲染逐像素一致，整章首次显示生成含服务启动由 98.035 秒降至 47.243 秒。

这两个比较属于不同阶段：**206 → 244 是填充修复的收益；Rust 重构是保持修复后 244 段效果不变并改善运行方式和显示性能。**不能把新增填充或更好的译文归因于换用 Rust。

稳定分支 `main` 仍保留 `a08b421`，另有标签 `stable/pre-rust-20261108`。Rust 分支已推送，收尾代码提交为 `75819f2`，未合并到稳定版。当前应用为本机开发候选版，仍依赖完整 checkout、原生依赖、Python 环境和模型，不是独立安装包。

- 第 13 页：背景旁白不再铺长白条，按顺序合并横排并局部修补网点；17 段已有译文可显示。

## 当前架构与运行

| 实现 | 当前职责 |
| --- | --- |
| Swift | 界面、连接设置、中文横排及最终绘制 |
| Rust / 原生库 | 页处理与队列、取消/恢复、OCR 页面组装、分镜分组、HTTP 与翻译协议、图像编码、缓存和原子编辑、蒙版/背景合成、本地自有引擎管理 |
| Python | CTD、Manga OCR、LaMa 模型推理，以及模型需要的预处理和输出转换 |
| oMLX / Ollama | 现有语言/视觉模型服务，推理引擎本身未迁移 |

不是完全去除 Python；候选版已经不调用旧 Python 业务 worker。Windows 仍保留原实现，未宣称完成跨平台 Rust 接入。

依赖准备见 [macOS 运行指南](../macos/README.md)。在独立分支根目录执行 `./macos/scripts/build_and_run.sh --verify`，生成并启动 `macos/dist/Koma Rust 候选版.app`。旧 `macos/启动.command` 仍指向稳定版名称，不作为候选入口。移动 checkout 后要重新构建。

候选版使用 `~/Library/Application Support/KomaReaderRust/`：`config.json`、`pages/`、`pages/vision-v1/`、`reading-native-v1/`。稳定数据在 `KomaReader/`，首次只读复制到独立候选副本。服务地址、Key、模型可固定在权限 `0600` 的本地配置中；不勾选记住 Key 则只保留在本次运行。当前不访问钥匙串，正式安装包及后续凭据方案仍可单独规划。

## Rust 验收与性能

| 类别 | 已完成验证 | 能说明什么 |
| --- | --- | --- |
| OCR | 真实模型顺序执行两套流程，35 页 259 块结构化结果一致 | 本组样本识别/页面组装等价，不代表 OCR 正确率提高 |
| 显示 | 35 页最终 Swift 像素和布局审计一致；244 段已有译文，无新增漏排/越界/丢字 | 保留修复后的填充效果 |
| 翻译 | 普通 209 场景、385 次模拟请求；视觉 100 场景、103 次原生调用、117 次模拟请求 | 请求、校验、手改保护、保存与错误恢复一致，不是实模型语义评测 |
| 图片输入 | 35 页 + 56 个格式/尺寸/EXIF 等案例，JPEG 字节一致 | 保持视觉模型输入兼容 |
| 应用交互 | 8 项控制器、6 项真实窗口流程通过 | 编辑刷新、换页、队列、取消和错误恢复覆盖；不代表穷尽所有鼠标键盘事件 |
| 生命周期与缓存 | 11 项原生测试通过；重启后 35 页持久缓存命中，推理适配器不可用仍可读取 | 自有进程清理、异常隔离及缓存持久性 |
| 正式入口 | 修复自身 bundle ID 作为 UserDefaults suite 强制解包的启动崩溃；真实应用窗口与持续存活另行验证 | 补足注入测试配置未覆盖的正式初始化路径 |

| 显示计时 | Python 稳定版 | Rust 候选版 |
| --- | ---: | ---: |
| 35 页首次生成，含服务启动 | 98.035 秒 | 47.243 秒 |
| 首次生成单页中位数 | 2.027 秒 | 0.705 秒 |
| 三轮缓存命中共 105 次 | 13.259 秒 | 0.751 秒 |
| 缓存命中单页中位数 | 125.49 毫秒 | 6.54 毫秒 |

固定原图与译文，独立空显示缓存后进行三轮缓存复用；不计编译和界面绘制，没有强制清空系统文件缓存。Rust 总耗时包含 0.823 秒服务启动及客户端 JSON 解码。首次整章约快 2.1 倍、缓存命中中位数约快 19.2 倍，包含持久进程与缓存设计收益，不能全部归因于语言。

Rust 所属进程 RSS 采样合计最高约 9.77 GiB，旧版单页 `time -l` 最高约 11.54 GiB，统计口径不同，不能据此判断内存降低。常驻模型保留内存是复用策略的代价。本轮没有以 Rust 重构重新执行真实语言模型翻译，也没有启停共享 oMLX 服务。
