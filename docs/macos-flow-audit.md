# Mac 阅读与翻译流程检查 · 2026-11-18

本次沿项目根目录的「启动 Rust 候选版.command」检查本机候选版。下表列出能由代码或测试确认的问题，以及已采用的修法。

| 使用场景 | 原先会发生什么 | 已采用的修法 |
| --- | --- | --- |
| 保存对白时切走又翻回 | 页面可以先读到保存前的快照，保存成功后仍显示旧译文。离开页面时保存成功的草稿也可能挡住后续译文 | 保存完成后按当前页面重新取结果和版本号，释放已成功保存的离屏草稿，保留保存失败的草稿。见 [阅读器](../macos/Sources/KomaReader.swift) 和 [草稿状态](../macos/Sources/ReaderWorkspaceState.swift) |
| 停止批量处理或超分 | 状态栏提前显示“已停止”。按下停止后才送达的落盘结果可能不会显示，停止超分也可能使当前页已有译文消失。读页失败后偶尔仍提示正在读取 | 等后台确认停止，再按实际开工页刷新。停止当前页增强时用原图重新加载已有译文，读页失败显示终态。见 [阅读器](../macos/Sources/KomaReader.swift) |
| 打开后原图被另一张同尺寸图替换 | 旧识别框仍可能套在新图上，手工修改也可能写入旧缓存 | 在生成回填和处理带图的手改请求时校验原图的内容摘要。不匹配就提示重新打开，保留原有记录。见 [页面处理](../core/src/runtime.rs) |
| 整章中有一份结构损坏的旧缓存 | 单页异常可能中断后续队列，甚至从坏记录生成另一种模式的缓存 | 在读取或导入时检查尺寸、文字块编号和对白结构。该页报错，队列继续，保留原文件供恢复。见 [缓存校验](../core/src/persistence.rs) |
| 保留原框期间换模型，再恢复翻译 | 旧模型留下的自动译文可能被当作新模型的结果跳过 | 按文字块追踪自动译文来源。旧记录无法判断来源时保留可读内容，在下次翻译请求时重新计算。手改译文继续保留。见 [翻译流程](../core/src/translate_pipeline.rs) |
| 翻译前模型已被移除或服务返回无效的模型列表 | 模型检查报错时，调用方内存里的页面可能已经换了模型并清除了自动译文 | 在临时页面上准备本次请求，模型检查成功后才采用新状态。已有缓存足够时可离线完成。普通与视觉模式均验证错误返回后页面内容和保存记录。见 [普通翻译](../core/src/translate_pipeline.rs) 和 [视觉辅助](../core/src/vision_pipeline.rs) |
| 彩页上的临界色笔画 | 缓存复核和回填通过不同方式转灰度，同一块文字可能一处判为正常，另一处判为缺少笔画 | 复核、识别和回填采用同一灰度转换，并用临界色样本对照两个入口。见 [图像处理](../core/src/imaging.rs) |
| 导出 Display P3 彩页 | 全页经过 SwiftUI 渲染，加入一处译文就会改变气泡外的颜色 | 仅渲染透明的译文层，再按底图色彩空间合成。像素测试同时检查译文的位置和译框外的底色。见 [章节导出](../macos/Sources/ChapterExport.swift) |
| 处理服务在写入请求时意外退出 | 写入已关闭的管道可能让阅读器一起退出 | 让该管道的写入失败成为可处理的错误，终结中断的请求，下一次操作可重启服务。见 [服务连接](../macos/Sources/NativeCoreService.swift) |
| 首次导入旧接口配置，或使用带编码路径的服务地址 | 首次导入绕过文件类型与大小检查，异常文件可能让启动停住。地址中的 `%2F` 也可能被改成真正的路径分隔符，实际连接到另一个路径 | 只读导入沿用同一套文件校验，保留旧文件权限；地址规范化保留路径编码。见 [本地接口配置](../macos/Sources/TranslationLocalConfig.swift) |
| 漫画目录只含 `.tif` 页 | 导入器能识别 `.tiff`，却将使用短扩展名的目录报为空 | 同时接受两个扩展名，使用真实 TIFF 文件验证大小写和首张图加载。对应本地用例位于 `macos/tests/ReaderConcurrencyTests.swift` |

## 验证与发布建议

- 本机 Qwen3 4B 对两张自带样图从头执行 OCR、翻译和回填，可检查模型环境、请求、缓存与显示能否衔接。样图英文页眉中的 “OCR TEST” 仍有字符误识别，涉及混排标题时建议对照原图校对。
- 35 页已有章节用于测试批量队列、快速翻页、手改重载、取消和失败后重试。连接故障使用本机可控的模拟接口。真实窗口检查覆盖原图与中文视图切换、缩放和坏缓存恢复。
- 60 页历史 OCR 材料共有 470 个文字块，修复前后作为参照的 9 处疑似框编号逐页一致。此对照用于发现既有判定变化。真实 oMLX 视觉模型的译文质量仍需用人工校对的篇章单独评估。
- 后续发布建议保留两类检查。保存和停止处理使用本地 `ReaderConcurrencyTests.swift` 控制回复先后顺序。修改绘制或超分代码时，用本地 `ChapterExportTests.swift` 核对气泡外的广色域底图，同时确认译文字形确实画出。运行方式见 [开发说明](development.md)。
