# 1209806 整章中文填充检查与修复

检查对象：35 张图片及已有视觉翻译缓存。基线为 Git `a550502`。本轮不重译、不修改漫画原图或已有日文/中文缓存；显示结果单独重建。

## 方法与边界

1. **清字**：复用本地 Comic Text Detector 的逐像素蒙版，合并高置信度检测结果，补齐白底上的细小残笔和长划线；清除范围受已翻译文字范围、气泡轮廓和邻近画面约束。
2. **背景**：纯色区域局部修补；网点、渐变和画面背景使用本地 Anime LaMa，仅将文字蒙版内的像素贴回。蒙版外像素保持原样，不铺整块白色矩形。背景重建属于估计，不能承诺恢复被原字遮住的真实细节。
3. **排版**：中文从左到右、从上到下；依据真实字宽和每行的轮廓空间换行；保留段落、标点和字号下限。黑底使用白字黑描边，浅底反之。
4. **漏填**：补充矩形旁白框、灰底/透明气泡、页底被截断的气泡和原文字范围内的回退排版。连续背景旁白先检查分镜边界，再按原阅读顺序合并，避免跨栏。
5. **缓存**：显示资产存于 `~/Library/Application Support/KomaReader/reading-v3/`，与翻译缓存分离；原图、译文、算法或模型变化使显示资产失效，不要求重译。
6. **疑似误识别**：很小的边角页脚标记保留原图并提示核对，手动修正保存可以覆盖；相同数字、没有译文的纯标点不冒充漏填。

模型来源与固定校验值见 [IOPaint AnimeLaMa 适配器](https://github.com/Sanster/IOPaint/blob/main/iopaint/model/lama.py)。安装脚本为 `macos/scripts/setup_reading_model.py`；阅读过程中不联网下载模型。

## 验证方式

`macos/tools/review_chapter.py` 使用阅读器同一份 SwiftUI 排版和绘制代码逐页导出图片。检查每个字形连同描边的边界、文字完整性、修补蒙版外像素，并对比原图和翻译缓存的 SHA-256。生成图片仍须逐页目视检查。

本地对比图片与逐字检查数据位于 `macos/.runtime/full-chapter-review/`。这批图片是私人本地检查材料，不加入 Git。自动检查不能证明没有 OCR 漏检、语义错误或纹理重建痕迹。
